**When to use this:** you're reviewing a PNR that automation (CIS) has queue-placed with a
remark, and need to know what triggered the queue placement and what action is expected of you.

<Admonition type="danger" title="Ticket status E overrides the remark">

If ticket status is **E**, do **not** cancel the booking — even if the automation remark says
`C2A CLK RESP/PSGR REQUESTS CANCEL`. Verify current ticket status before acting on any automated
remark.

</Admonition>

## The flow

```mermaid
flowchart TD
    A[CIS evaluates the PNR] --> B{Trigger}
    B -->|Within imminent travel window| C[C2A ELIGIBLE — email sent, QP to Imminent queue]
    B -->|Customer clicked Accept, GDS update failed| D[C2A AUTO ACCEPT FAILED — QP to CAT]
    B -->|Customer clicked Call Me| E[C2A CALLBACK REQUEST — QP to Call Back queue]
    B -->|No response after holding window| F[C2A PAST AGED DATE — queue removed, no email]
    B -->|Customer accepted C2A| G[Review PNR / MCT, issue exchange]
    B -->|Customer clicked Cancel| H[Review, cancel segments, process refund<br/>unless ticket status is E]
    B -->|Schedule change / MCT-GDS error| I[Review hold queue — email sent or not, per remark]
    B -->|Identical HK/E-ticket match| J[Cleaner-scanned QR — no action needed]
```
